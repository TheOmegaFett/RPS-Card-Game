# APPENDIX

**Rock Paper Scissors React App (v1.0.1)**

A modern re-imagining of the classic Rock–Paper–Scissors card game, built in React.js, powered by a custom NPM logic package, and deployed as a static web app via Render.

## 💬 Reflection

This project bridges academic theory with professional-grade workflow.

Through iterative development, I learned to:

- **Architect maintainable React applications** with modular design patterns
- **Manage modular codebases** across multiple packages and dependencies
- **Use AI and Git as collaborative tools** for growth and efficiency
- **Deliver a fully deployed, documented product** from concept to release

Building this project reinforced a developer mindset of **clarity, discipline, and curiosity** — using emerging tools to enhance craftsmanship, not replace it.

### Key Takeaways:

1. **AI is a tool, not a crutch** - Understanding every line of code is essential
2. **Documentation matters** - Good docs make projects accessible and maintainable
3. **Modular design pays off** - Extracting logic into NPM package enabled reusability
4. **Professional workflows** - Git, testing, and deployment practices are crucial
